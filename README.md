# Observability Lab

Repositorio personal para aprender y practicar observabilidad desde la base.

La idea es trabajar con datos reales del sistema, entender cómo se comportan los servicios y avanzar progresivamente hacia herramientas como OpenTelemetry, Prometheus, Grafana y AWS.

## Objetivos

- Entender los fundamentos de observabilidad.
- Trabajar con métricas, logs y trazas.
- Analizar sistemas Linux.
- Crear scripts de automatización con Python.
- Practicar monitoreo y alertas.
- Aprender OpenTelemetry Collector.
- Trabajar con contenedores.
- Llevar parte del laboratorio a AWS.
- Documentar pruebas, errores y soluciones.

## Tecnologías

- Linux
- Git / GitHub
- Python
- Docker
- OpenTelemetry
- Prometheus
- Grafana
- AWS

## Metodología

El repositorio irá creciendo con prácticas reales.

Cada laboratorio incluirá:
- comandos utilizados
- pruebas realizadas
- capturas o evidencias
- errores encontrados
- solución aplicada
- conclusiones

## Estado

Actualmente comenzando con fundamentos de observabilidad y análisis básico del sistema Linux.
